🎯 Executive Summary (Portfolio Highlights)

NetForge: Cyber Defense Edition is a browser-native discrete-event network packet tracer and cybersecurity SOC simulator. Unlike mock UI animations, every frame hop, ARP broadcast, L2 MAC table lookup, L3 Longest-Prefix-Match route decision, Stateful Firewall ACL evaluation, and WAF/IDS payload inspection is computed deterministically by the protocol state machine.

🌐 Networking Stack Implemented
  • Layer 2 Ethernet: Source MAC learning, unicast forwarding, unknown unicast/broadcast flooding, same-port filtering.
  • Dynamic ARP & DAI: Broadcast ARP Request (Opcode 1), Unicast Reply (Opcode 2), pending packet queue, Dynamic ARP Inspection anti-spoofing.
  • Layer 3 IPv4 Routing: Bitwise CIDR calculations, Longest-Prefix-Match (LPM), TTL decrement, L2 MAC header re-encapsulation per hop.
🛡️ Cyber Attack & Blue-Team Matrix
  • Nmap SYN Recon & SSH Brute-Force: Mitigated via Stateful Firewall Port/Protocol ACLs (`DENY TCP/22`).
  • ARP Cache Poisoning (MITM): Gratuitous ARP spoofing blocked via Switch Dynamic ARP Inspection (`DAI`).
  • SQL Injection (`' OR 1=1--`): L7 payload signature detection via Deep Packet Inspection WAF/IDS.
  • Botnet SYN Flood (DDoS): Mitigated via Stateful SYN Rate-Limiting & Decoy Honeypot redirection.
