# NetForge Protocol Simulation Specification

NetForge implements a modular, inspectable protocol stack with deep Layer 2, Layer 3, and Layer 4 header modeling.

---

## 1. Supported Protocols

### Ethernet (IEEE 802.3 / DIX Ethernet II)
- **Destination MAC (6 bytes):** 48-bit hardware address (unicast or broadcast `FF:FF:FF:FF:FF:FF`).
- **Source MAC (6 bytes):** 48-bit transmitting hardware NIC address.
- **EtherType (2 bytes):**
  - `0x0806`: Address Resolution Protocol (ARP).
  - `0x0800`: Internet Protocol version 4 (IPv4).
- **Payload:** Encapsulated ARP packet or IPv4 packet (46 to 1500 bytes MTU).
- **Frame Check Sequence (FCS):** Simulated 32-bit CRC checksum verification.

### Address Resolution Protocol (ARP, RFC 826)
- **Hardware Type:** Ethernet (1).
- **Protocol Type:** IPv4 (`0x0800`).
- **Hardware Length:** 6 bytes (MAC).
- **Protocol Length:** 4 bytes (IPv4).
- **Operation:**
  - `REQUEST` (Opcode 1): Broadcast query asking "Who has target IP? Tell sender IP".
  - `REPLY` (Opcode 2): Unicast answer informing "Target IP is at target MAC".
- **Dynamic Learning:** All hosts and routers inspect incoming ARP Requests to learn the sender's MAC in their ARP cache (gratuitous ARP learning), eliminating duplicate requests.

### Internet Protocol version 4 (IPv4, RFC 791)
- **Version:** 4.
- **Source IP (4 bytes):** Originating host or router interface IPv4.
- **Destination IP (4 bytes):** Destination host IPv4.
- **Time-to-Live (TTL, 1 byte):** Initialized to 64; decremented at each router hop.
- **Protocol (1 byte):**
  - `1`: Internet Control Message Protocol (ICMP).
  - `6`: Transmission Control Protocol (TCP).
  - `17`: User Datagram Protocol (UDP).
- **Identification & Flags:** DF (Don't Fragment) flag.

### Internet Control Message Protocol (ICMP, RFC 792)
- **Type 8, Code 0 (Echo Request):** Formatted ping probe containing sequence number and 32-byte payload.
- **Type 0, Code 0 (Echo Reply):** Ping response generated by target host or router interface.
- **Type 11, Code 0 (Time Exceeded):** Generated by a router when a transit packet's TTL drops to 0.
- **Type 3 (Destination Unreachable):**
  - `Code 0`: Network Unreachable (no matching route in routing table).
  - `Code 1`: Host Unreachable (ARP resolution failure or no gateway).

---

## 2. Protocol Boundaries and Limitations

NetForge focuses on high-fidelity simulation of core fundamentals:
- **Fully Implemented:** Ethernet, ARP, IPv4, ICMP (Echo, Reply, Time Exceeded, Unreachable), Static Routing, Default Routing, MAC Learning, Subnetting.
- **Roadmap / Future Work:**
  - Dynamic Routing: RIP, OSPF, BGP.
  - VLANs & Trunking: IEEE 802.1Q tag encapsulation and Inter-VLAN routing (Router-on-a-Stick).
  - Spanning Tree Protocol (STP): Loop prevention.
  - Network Address Translation (NAT / PAT): Overload translation.
  - Stateful Layer 4 TCP three-way handshake and UDP sockets.
